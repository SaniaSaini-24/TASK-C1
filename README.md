# SIT313 C1 – New Post Page

## About
This task is about creating a New Post page for the DEV@Deakin website using React and CSS. Users can select Question or Article and fill in the required details.

## Features
- Select Question or Article.
- Enter title and post details.
- Add up to 3 optional tags.
- Validate required fields.
- Show success and error messages.

## How to Run
1. Open the project folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.
5. Click **Post** to open the New Post page.

## Note
This task demonstrates form validation and submission. Posts are not saved to a database.
